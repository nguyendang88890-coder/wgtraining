# WG Training Portal

Training portal cho nhân viên WeGolden (bản Global, thương hiệu WeGolden — không phải WeMasterTrade). Static HTML/CSS/JS thuần, không build step — backend là Firebase Realtime Database (project `wgtraining-a669d`, **độc lập** với project Firebase của web WMT cũ (`wmt-training-portal`, có ~140 user thật của web khác) — không bao giờ trỏ nhầm hoặc migrate dữ liệu giữa 2 project này).

- **Xác thực = Firebase Auth email + mật khẩu** (không còn Anonymous Auth, không còn mật khẩu/hash trong database, không có tự đăng ký). Chuỗi nhận diện: Auth `uid` → `uidmap/<uid>` = username → `users/<username>` (role, isLeader, leaderName...). Tài khoản chỉ do admin tạo (`admin.html` → Add User dùng `createAuthAccount`, ghi `uidmap` + profile nguyên tử rồi mới commit). Quên/đặt lại mật khẩu: email reset của Firebase (`sendResetEmail`) — admin **không xem được** mật khẩu, đừng thêm tính năng lưu/hiện mật khẩu dạng rõ.
- `firebase-config.js`: cấu hình Firebase (chọn môi trường: không phải localhost → prod; localhost → **staging** `wgtraining-staging` mặc định, đổi sang prod bằng `localStorage.wg_env='prod'`, có badge "STAGING DATA") + auth helpers (`getSession`, `requireSession`, `loginWithEmail`, `logoutUser`, `changeOwnPassword`...) + lớp đồng bộ `localStorage` ⇄ Firebase (`dbWrite`, `dbRemove`, `fbUpdate`, `syncFromFirebase` theo role: trainee chỉ tải dữ liệu của mình, leader thêm team, mod/admin rộng hơn). Đọc dữ liệu ở phía app qua `localStorage`; ghi qua `window.dbWrite`/`window.dbRemove`/`window.fbUpdate`; quyền thật nằm ở Security Rules, **không tin `localStorage`/role phía client**.
- **Security Rules**: sinh từ `firebase/build-rules.js` → `firebase/database.rules.json` (deny-by-default). Sửa rules = sửa `build-rules.js`, chạy `node firebase/build-rules.js`, chạy bộ test tấn công `node tools/rules-test/run.js` (chỉ chạy được trên staging, phải 141/141 đạt), deploy staging trước (`npx firebase-tools deploy --only database --project staging`), prod sau (`--project prod`). Bản rules cũ (trước migrate) lưu ở `C:\Users\T490\wg-backups\` (ngoài repo, không commit).
- `module-common.js`: logic & UI dùng chung (sidebar, quiz engine MCQ, chuông thông báo, feedback gate...) cho hầu hết các trang — nạp sau `firebase-config.js`.
- 5 module đào tạo: `module1.html` (Overview) → `module5.html` (Deposit & Withdrawal, gồm cả Savings Feature). Mỗi module có mini-quiz **trắc nghiệm** (giữ nguyên MCQ).
- **Final Exam (`exam.html`) là dạng tự luận (Essay)**, không phải trắc nghiệm — trainee viết câu trả lời, admin chấm điểm thủ công qua `admin.html` (modal "Grade Exam"). Nộp bài xong vào trạng thái `pending_grading`, không tính lượt thi cho tới khi admin chấm xong. Ngưỡng đậu: 60% (lần 1) / 80% (lần 2), khoá 3 ngày sau khi rớt lần 1, loại sau lần 2. Answer Guide (rubric) **chỉ admin thấy khi chấm**, không hiện cho trainee lúc làm bài.
- Trainee đã hoàn thành Final Exam + Interview (`completed`) nhưng chưa gửi feedback sẽ bị chặn bởi modal bắt buộc đánh giá (feedback gate, logic trong `module-common.js` + `index.html`) ở mọi trang cho tới khi họ submit.
- Các trang chính khác: `index.html` (dashboard học viên), `admin.html`, `leader.html`, `monthlytest.html`, `interview.html`, `tracker.html`, `results.html`, `taketest.html`, `feedback.html`.
- Deploy: push lên `main` → GitHub Actions SSH vào VPS bằng deploy key bị giới hạn (forced command trong `authorized_keys` chạy `/usr/local/bin/deploy-training.sh`). Script `git pull` repo đặt **ngoài** web root (`/var/repos/training`) rồi `rsync` chỉ các file của site vào `/var/www/training.wegolden.com` (loại `.git`, `.github`, `.claude`, `CLAUDE.md`, `README.md`, `ss_*.png`, `firebase/`, `tools/`, `firebase.json`, `.firebaserc`). Nginx còn chặn mọi dotfile (`location ~ /\.(?!well-known) { return 404; }`) — không bao giờ để `.git` nằm trong web root. Phục vụ tại `training.wegolden.com` qua Nginx + Certbot.
- Chạy local: `npx serve -p 3030 .` (đã cấu hình sẵn trong `.claude/launch.json`).
- Đây là project độc lập, không dùng chung `.env`/database với bất kỳ project nào khác trên máy. Firebase API key trong `firebase-config.js` là client-side config (không phải secret), bảo mật thực sự nằm ở Firebase Security Rules (xem trên). Rủi ro còn lại đã biết: chấm điểm quiz/exam tự động chạy phía client (trainee có thể gian lận điểm quiz), rubric/đáp án nằm trong JS tĩnh của một số trang. Không bao giờ bật lại Anonymous Auth hoặc nới rules thành `auth != null`.
